# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AlphaFitApi, please do not
open a public issue.

Instead, report the vulnerability privately to the repository maintainer,
including:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation, if available

Security reports will be reviewed and investigated as soon as possible.

## Supported Versions

Currently, only the latest version of AlphaFitApi is supported with
security updates.
